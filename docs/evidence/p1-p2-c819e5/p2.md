D0001 now distinguishes retained immutable attempt identity from held capacity.
Full identity and observer epoch fence settlement; confirmed termination releases

precedes lookup, but an existing logical request is found before obsolete deadline
checks. Short SQLite transactions use connection-lifetime OS exclusion; work and
attempt conflicts have partial unique indexes, not a global execution queue lock.
Object publication uses verified immutable bytes, atomic same-filesystem rename and
file/directory fsync, not hardlinks to writable candidates or a hidden host fallback.

row limit is explicit 2 MiB; it is not an increase to the public request budget.
